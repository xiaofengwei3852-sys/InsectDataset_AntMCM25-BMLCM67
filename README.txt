昆虫图像数据集AntMCM25 & BMLCM67 / Insect Image Datasets

本数据包包含两个按物种类别组织的昆虫图像数据集，图像来源为全球生物多样性信息机构 GBIF（https://www.gbif.org/）。

AntMCM25：25 个蚂蚁物种类别，属于膜翅目蚁科。现有 13,602 个 JPG 文件；类别目录连续编号 01-25，并保留学名。

BMLCM67：67 个鳞翅目蝶蛾类别。现有 66,420 个 JPG 文件，类别目录连续编号 01-67，并保留学名。

每个数据集均包含 images/ 图片目录、类别信息 Excel、images.txt 路径清单、image_class_labels.txt 类别清单及独立 readme.txt。Excel 的类别 ID、目录编号和标签清单一致。类别特征、分布等描述属于类别级信息。

详细类别、文件数量、格式与来源说明，分别见 AntMCM25/readme.txt 和 BMLCM67/readme.txt。

English
This package contains two species-organized insect image datasets collected through GBIF (https://www.gbif.org/).

AntMCM25: 25 ant species classes within Formicidae, Hymenoptera; 13,602 JPG files. Class prefixes run from 01 to 25, retaining scientific-name suffixes.

BMLCM67: 67 butterfly/moth classes within Lepidoptera; 66,420 JPG files. Class prefixes run from 01 to 67, retaining scientific-name suffixes.

Each dataset provides images/, an Excel class workbook, images.txt, image_class_labels.txt, and its own readme.txt. Workbook IDs, directory prefixes, and manifest labels agree. Descriptive metadata is class-level information. See each dataset's readme.txt for its full class list, counts, formats, and provenance notes.
